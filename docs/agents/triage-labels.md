# Triage Labels

These are the canonical Matt Pocock triage roles and their Linear labels.

| Role | Linear label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

Category labels are:

- `bug` → `Bug`
- `enhancement` → `Feature` for new capabilities, or `Improvement` for
  existing behavior improvements

Wayfinder labels are:

- `wayfinder:map`
- `wayfinder:research`
- `wayfinder:prototype`
- `wayfinder:grilling`
- `wayfinder:task`
